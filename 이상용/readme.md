# 커뮤니티

- 네이버의 band 앱을 벤치마킹
    - ex) 관심가는 팀의 소규모 모임 생성
- 메인페이지에서 상단 네비바를 통해 커뮤니티 페이지 이동
- 커뮤니티 메인에 관심 분야(팀) /  내가 가입한 소모임 리스트 / 위치기반 소모임 리스트 보여주기
    - 리스트 중에 내가 가입하고자 하는 모임 클릭하면 해당 소모임 페이지로 이동
        - 해당 소모임 맘에 들시, 가입하기 버튼을 통해 가입 신청
    - 직접 모집하는 기능 ( 시판에서 글쓰기와 유사한 느낌)
        - 모집 시 제목 / 관심 있는 팀 / 지역 / 모집 조건 (성별, 나이 등)
- 모임 내에서 글쓰기 기능
    - 댓글, 좋아요 등 다양한 기능 추가
